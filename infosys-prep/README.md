# Infosys SP/DSE prep guide

- `website/index.html`: the single-file guide (Start here, Infosys questions, Codeforces DP, Greedy, CF Top 150, Plan, How scores work).
- `cf_dp_scored.csv`, `infosys_sp_dse_prep_full.xlsx`, `infosys_sp_dse_questions_full.csv`: scored data.
- `cf/`: problem lists and the TSV batches used to build the Greedy section.
- `raw_notes/`: per-problem study notes (pattern, solution, dry run, C++, confidence).
- `scripts/`: `build3.py` builds the data; `update_site.py` and `plan_inject.py` update the page; `smoke.js` and `greedy_check.js` are Playwright checks.

Source question files are not included.
